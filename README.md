# Cromo Marketing — Landing Page

Landing page premium para a Cromo Marketing, agência de Enzo Gomes especializada em produção audiovisual, posicionamento e crescimento para hamburguerias.

## Tecnologias

- HTML5 semântico com metadados de SEO e dados estruturados
- CSS3 responsivo com grid, glassmorphism e animações performáticas
- JavaScript ES6 sem dependências para navegação, reveals, modal e microinterações
- Deploy estático compatível com Netlify
- Headers de segurança e cache configurados em `netlify.toml`

## Executar localmente

Abra `index.html` diretamente no navegador ou sirva a pasta com qualquer servidor HTTP estático. No ambiente Netlify, use `netlify dev --port 8889`.

## Personalização antes da publicação

- Substitua `assets/enzo-placeholder.jpg` pelo retrato oficial de Enzo Gomes.
- Atualize os links de Instagram e WhatsApp em `index.html`.
- Troque os números ilustrativos do case pelos resultados auditados da Adega do Bigode.
- Substitua `assets/hero-film.mp4` pelo filme gastronômico final, mantendo o mesmo nome para evitar alterações no HTML.

As imagens atuais são assets editoriais de demonstração armazenados localmente para preservar velocidade e estabilidade visual.
